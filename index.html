How CyberBuddy scores

python · cache · live

Clickjacking

Restrictive frame-ancestors is low risk. X-Frame-Options alone is medium. frame-ancestors * or neither control is high. The live iframe is the proof — if the real UI appears, the page can be framed in this browser.

Headers (0–100)

CSP 25 · XFO 15 · HSTS 15 · nosniff 10 · Referrer-Policy 10 · Permissions-Policy 5 · COOP/COEP/CORP 5 each. A ≥ 90, B ≥ 75, C ≥ 60, D ≥ 45, else F. Every finding shows the raw value it used.

CORS

The Python engine probes two origins to prove reflection vs an allowlist. On GitHub Pages the browser can only speak as this origin — a single-origin probe, labelled honestly on the report.

Hosted scan layers

Python when server.py or api/ is up. Otherwise a same-origin cached report from urls.txt (fresh within 48h). Otherwise a live header lookup. The source chip always says which layer ran.

Keyboard: / focuses the URL, t toggles theme, ? opens shortcuts. Authorized testing only — IANA example hosts and this GitHub Pages origin are the cached demos.
