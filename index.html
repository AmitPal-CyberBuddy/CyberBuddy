CyberBuddy runs read-only browser security checks against URLs you provide — clickjacking protections, security headers, and CORS posture. Pick a tool below. Scans run locally; nothing leaves your machine.

Why it exists

  • Clickjacking is still the silent frame-job of the web — one missing header and your login page can be trapped under a decoy.
  • Headers like X-Frame-Options, CSP and HSTS are boring, tiny, and absolutely load-bearing.
  • Tool sprawl is real: CyberBuddy puts the checks you actually run in one place, with one look.
! ! Authorized testing only. Point CyberBuddy at systems you own or have written permission to assess. All checks are read-only GET requests; the iframe test is visual only and can't read cross-origin content.

How it works

01 · pick a target

Enter any http(s) URL. If the local scan engine is running, checks run server-side; otherwise pages fall back to static mode.

02 · scan locally

Header checks run through server.py on your machine. Nothing is uploaded, logged remotely, or shared — the API is localhost-only by design.

03 · see the evidence

Every finding shows the actual header value it was based on. Clickjacking additionally shows a live iframe test and a shareable PoC overlay.

! ! Authorized-testing disclaimer. CyberBuddy is a security-testing aid. You may only scan systems you own or are explicitly authorized to test. The clickjacking tool loads target pages in an iframe — some sites block that by design, which is itself a finding. Results are advisory and never a guarantee of safety.
