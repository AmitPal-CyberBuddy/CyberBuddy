ℹ How this check works

This tool reads a domain's public DNS records — it never connects to the domain's own servers. The Python engine sends DNS queries to your system resolver; on the hosted site the same lookups run over DNS-over-HTTPS (Google Public DNS) after your consent and are labelled unverified.

Domain→ DNS query →Resolver→ records →Grade A–F

Each check shows the raw record value it used. A missing DKIM key on common selectors is labelled honestly — it is not proof that no key exists.
