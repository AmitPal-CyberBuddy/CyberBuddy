Static mode — header checks need the local engine

This page is being served without server.py, so the browser can't read another site's response headers (that needs a server-side proxy — browsers block it). The visual iframe test above works anyway. To enable full header scoring, run:

python3 server.py

then open http://127.0.0.1:8080/. The CLI works standalone too: python3 clickjacking_validator.py https://example.com.

! ! Authorized testing only. You may only scan systems you own or have explicit permission to assess. The frame test is visual by design: cross-origin documents can't be read by script, so a blank frame vs. a rendered UI is the signal — never treat either as proof of vulnerability without authorization and context.
