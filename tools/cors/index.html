ℹ How this probe works

This page fetches the target as a cross-origin caller — exactly what a hostile website would do to read your data. The browser enforces CORS, so the probe measures the real policy from outside.

This page (caller origin)→ GET →Target server→ ACAO decision →Allow / block

On the hosted site this is a single-origin probe. The Python engine probes a second origin to prove whether Access-Control-Allow-Origin reflects any caller or honors an allowlist.
