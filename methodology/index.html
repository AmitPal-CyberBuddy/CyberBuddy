How it scores

Methodology

Three read-only checks, the same graders in Python and in the browser, and a report card you can paste into an assessment. Authorized testing only.

What each tool proves

Clickjacking Validator

Reads X-Frame-Options and CSP frame-ancestors, then loads the target in a live iframe. If the real UI appears, the page can be framed in this browser — that is the proof, not just the headers.

OWASP WSTG-CLNT-09 · CWE-1021

Security Headers

Grades ten header families on a 0–100 scale (A–F). Every finding shows the raw value it used. Cookie flags are checked when Set-Cookie is present.

OWASP WSTG-CONF-07 / CONF-12 · CWE-693

CORS Validator

The Python engine probes two fake origins to prove reflection vs an allowlist. On GitHub Pages, the browser can only speak as github.io — a single-origin probe, marked honestly.

OWASP WSTG-CLNT-07 · CWE-942

What it does not do

No exploits, no authenticated sessions, no POST/PUT/DELETE. Results are advisory. A green grade is not a guarantee of safety and a red grade is not a CVE.

Grade bands: A ≥ 90 · B ≥ 75 · C ≥ 60 · D ≥ 45 · F below that. Risk follows the grade (A/B low, C/D medium, F high).

How the hosted site scans

01 · Python engine

When server.py or a hosted api/ is reachable, every check uses the same stdlib engines as the CLI — including two-origin CORS.

02 · Cached report

GitHub Actions pre-scans the URLs in urls.txt every six hours. Fresh reports (under 48 hours) are served same-origin as cache/<host>.json and labelled via cached report.

03 · Live fallback

Otherwise the browser grades headers through a public read-only lookup (10-minute local cache) and probes CORS from this origin only. The source chip says so.

Authorized testing

You may only point CyberBuddy at systems you own or have written permission to assess. The hosted cache only includes IANA documentation hosts (example.com, example.org, example.net) and this project’s own GitHub Pages origin. Cloud-metadata and link-local addresses are always refused. Private RFC1918 targets are allowed only when server.py is loopback-bound (or you pass --allow-private).
