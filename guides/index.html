How these guides work

A guide is deliberately short. It states the weakness, the evidence that settles it, and the fix — then hands off. Anything that needs a full walkthrough (traffic captures, exploitation chains, tool internals) lives in the maintainer's Medium write-ups, not here.

Every guide is paired with a tool. Read the guide, run the matching check from the tools catalog, and the report card it produces is the artifact you attach to the finding. The scoring rules behind those report cards are documented on the methodology page.

! ! Authorized testing only. These guides describe read-only checks against systems you own or have written permission to assess.
